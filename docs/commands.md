# 指令規格

Bot 端（LINE / Telegram）支援的文字指令。系統架構與 Reply/Push 降級機制見 [architecture.md](architecture.md)。

| 指令 | 功能 | 狀態 |
|---|---|---|
| 傳送照片/文字 | 追加至當前餐次緩衝區 | ✅ 已實作 |
| `ok` | 結束當前餐次，觸發抓圖與 AI 辨識寫入 | ✅ 已實作 |
| `今日` | 查詢今日累計營養素 | ✅ 已實作 |
| `圖表` / `分析` | 傳送專屬 PWA 視覺化儀表板連結（含 Sheet ID） | ✅ 已實作 |
| `修正 熱量 700` | 修正最近一筆紀錄的數值欄位或餐次標籤 | ✅ 已實作 |
| `取消` | 清除目前緩衝區 | 🚧 規劃中，尚未實作 |
| `目標` | 回傳 `goals` 工作表連結 | 🚧 規劃中，尚未實作 |
| `設定 {Sheet ID}` | 綁定/更換 Google Sheet | 🚧 規劃中，尚未實作 |
| `說明` | 顯示指令列表 | 🚧 規劃中，尚未實作 |

## 實作細節備註

- `ok`：僅在緩衝區有照片或文字時觸發辨識；辨識完全失敗時仍會清空緩衝區並提示使用者重新拍照，避免無限重試。
- `今日`：依 Asia/Taipei 時區當天日期彙總 `daily_log`。
- `修正`：支援欄位別名 `熱量`/`碳水`/`蛋白質`/`脂肪`/`餐次`，僅修改**最近一筆**紀錄。
- `圖表`/`分析`：組出 `{WEB_BASE_URL}/?sheet_id={google_sheet_id}`，未綁定 Sheet 或 `WEB_BASE_URL` 未設定時會提示對應錯誤訊息。

> 目前程式碼中的多個錯誤訊息（例如尚未綁定 Sheet 時）會提示使用者輸入「設定 {Sheet ID}」，但該指令實際上**尚未實作**——目前綁定 Sheet 僅能由管理者直接編輯管理用 Google Sheet 的 `users` 工作表完成。這是已知落差，待補上。
